## Семь прецептов (кратко)

1. **Agency верифицируется, а не декларируется** — Metis, Ed25519-оракулы  
2. **Слабая агрегация — тирания** — бенчмарки регрессии совета  
3. **Доступ к инструментам — территория** — WARDEN / ARGUS  
4. **Invoke — контракт** — AIMarket Hub v2  
5. **Суверенитет gated** — ярусы capability, QA-шлюзы  
6. **Канон правят публично** — PR, Council vs Solo  
7. **Молчание лучше ложной уверенности** — honest-null reporting  

Полный текст: [CANON.md](../CANON.md)
