## Sept préceptes (résumé)

1. **L’agency est vérifiée, pas déclarée** — Metis, oracles Ed25519  
2. **L’agrégation faible est tyrannie** — benchmarks de régression du conseil  
3. **L’accès aux outils est territoire** — WARDEN / ARGUS  
4. **Invoke est contrat** — AIMarket Hub v2  
5. **La souveraineté est gated** — paliers de capability, portes QA  
6. **Le canon s’amende en public** — PR, Council vs Solo  
7. **Le silence bat la fausse certitude** — honest-null reporting
